# The Sheema Edit

The standalone source for [thesheemaedit.com](https://thesheemaedit.com), a playful Y2K personal blog by Sheema.

## What is included

* A responsive homepage
* An About page
* Four starter essays
* Topic filtering
* Mobile navigation
* Search and social metadata
* RSS feed and sitemap
* A custom 404 page
* No paid theme, database, or build system

## Publishing a new edit

Add each new story inside `posts`, link it from the homepage, and include it in `sitemap.xml` and `feed.xml`. GitHub Pages publishes updates from the `main` branch.

## Local preview

Run a basic web server from this folder and open the local address it provides.

```sh
python3 -m http.server 4173
```
